# Brand images

Home Assistant and HACS do not read icons from this repository — they load them from
[home-assistant/brands](https://github.com/home-assistant/brands). Until the images
below are merged there, the integration shows a generic placeholder in the HACS list
and on the Devices & Services page.

## Files

| File | Size | Purpose |
|------|------|---------|
| `icon.png` | 256×256 | Required |
| `icon@2x.png` | 512×512 | Required |

No `logo.png` is provided: brands falls back to the icon when a brand uses the same
image for both.

The design is the departure board itself — three line badges (U-Bahn blue, S-Bahn
green, Tram red) with yellow countdowns, drawn with the **same 5×7 pixel font the
Lovelace card uses**, so the icon and the card stay visually identical. It is
regenerated by `generate_icon.py`, which parses `FONT_5x7` straight out of
`custom_components/bvg_display/www/bvg-display-card.js`.

```bash
pip install Pillow
python3 brands/generate_icon.py
```

## Submitting to home-assistant/brands

1. Fork [home-assistant/brands](https://github.com/home-assistant/brands).
2. Copy both files to `custom_integrations/bvg_display/` — the directory name must
   match `domain` in `manifest.json`.
3. Open a pull request.

Requirements the images already satisfy: PNG, 1:1 aspect ratio, exact 256/512 pixel
dimensions, transparency, and trimmed edges.
